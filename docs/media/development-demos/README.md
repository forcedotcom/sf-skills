# Salesforce Development demo recordings

Recorded October 22, 2026, using Salesforce Development 2.5.0 and a dedicated
Developer Edition org. The Codex Lightning app also uses Experience LWC 0.3.0;
the Claude Code React app uses Experience React 0.2.1.

The GIFs loop; MP4s provide the same edits in a video player. These are selected
highlights from genuine terminal recordings plus still captures of the deployed
apps, rather than continuous desktop recordings. Speed changes are labeled.
The Claude Lightning installation excerpt verifies an existing installation;
the React excerpt shows installation in a new project.

## Verification

All three apps were deployed successfully and checked manually in the browser:

- Claude Lightning: six fictional Accounts, selected-account details, name search.
- Codex Lightning: six fictional Accounts, search, selection and matching details.
- Claude React: live Account data, industry filter, name search, detail navigation,
  and returning to the list with filters preserved.

No test suites were run. The sessions used installed skills and Salesforce CLI
while context MCP services were unavailable. They do not demonstrate MCP service
connectivity. Local account details were hidden in terminal renders, and the React
session email bar was cropped from the exported media.

Only final media is included here. Raw terminal captures, authentication material,
local project settings and dependencies are excluded.
